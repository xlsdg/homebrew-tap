# homebrew-tap

Homebrew tap for [xlsdg](https://github.com/xlsdg)'s apps.

## Usage

```bash
brew install --cask xlsdg/tap/flower-password
```

## Casks

| Cask | Description |
|------|-------------|
| [`flower-password`](Casks/flower-password.rb) | [FlowerPassword](https://github.com/xlsdg/flower-password-swift) — menu bar app that derives site-specific passwords with the Flower Password method |
